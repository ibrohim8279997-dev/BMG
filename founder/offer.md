# Оффер

## Проблемы клиента на пути к результату («дом построен без лишних трат и простоев»)

| Проблема | Решение | Стоимость для BMG | Ценность для клиента |
| --- | --- | --- | --- |
| Не знаю, сколько чего брать | Смета по объекту, **проверенная сметчиком** | низкая (разово) | высокая |
| Боюсь переплатить | Сравнение 3–5 продавцов с ценой «под ключ» (товар + доставка + сбор) | нулевая | высокая |
| Недовес и пересорт | Приёмка при доставке: отказ от несоответствующего товара без потери сбора | средняя (резерв 1%) | очень высокая |
| Не верю новому сайту | Сбор списывается **после** подтверждения доставки; первые заказы ведёт менеджер в Telegram | низкая | высокая |
| Мастер всё равно пересчитает | Смета отправляется мастеру ссылкой, мастер правит количество | нулевая | средняя |
| Несколько продавцов — кто отвечает | Один менеджер BMG на весь заказ | средняя | высокая |
| Привык к наличным | Остаток — наличными продавцу, онлайн только сбор | нулевая | высокая |

## Сборка: «BMG Смета+» (рабочее название)

- **Ядро:** смета по объекту + сравнение предложений + один ответственный менеджер.
- **Сбор:** 2% от товара, не более 300 000 сум на заказ, списывается после приёмки.
- **Гарантия (в пределах резерва CFO 1%):** недовоз или пересорт — BMG возвращает деньги за непоставленное за 3 рабочих дня или привозит замену у другого продавца; продавец не приехал — полный возврат сбора.
- **Бонусы (дёшевы в исполнении):** PDF-смета для мастера; напоминание о следующем этапе стройки; первый заказ без сбора (пилот, Ташкент, до 31.01.2027).
- **Отмена:** сбор не берётся, если клиент отменил **до отгрузки** (панель называла невозвратные 5% явным стоп-фактором). Сейчас код удерживает предоплату при любой вине клиента (`refund_order`, fault='client') — потребуется изменение правил.
